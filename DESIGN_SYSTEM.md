## DESIGN PHILOSOPHY

This system MUST NEVER feel like a generic inventory management system.

It should feel like enterprise software used by billion-dollar manufacturing companies.

The user should immediately think:

• Premium
• Professional
• Trustworthy
• Clean
• Modern
• Executive
• Data Driven

Imagine if Apple designed an ERP.

Avoid anything that resembles Bootstrap admin templates.

The interface should communicate confidence instead of decoration.

Every screen should look presentation-ready.

Less is more.

# ============================================
# CLAUDE REQUIREMENTS
# ============================================

Whenever generating UI:

Always think like a Senior Product Designer.

Do not produce generic admin templates.

Prioritize whitespace over decoration.

Use premium SaaS layouts.

Follow an 8-point spacing system.

Maintain perfect alignment.

Every component must be reusable.

Every page should look production-ready.

If unsure between two layouts,

always choose the cleaner one.

Design for enterprise users who spend
8+ hours inside the system.

Every screen should be something worthy
of a Behance or Dribbble showcase.
